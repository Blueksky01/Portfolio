Overview

โครงงานคืออะไร

SLCC Hub (Smart Life Care Center Hub) เป็นศูนย์กลางข้อมูล (Centralized Data Hub) สำหรับบริหารศูนย์พักพิงในสถานการณ์ฉุกเฉิน ครอบคลุมการติดตามสถานะความจุและผู้อาศัยแบบ Real-time การจัดการและกระจายทรัพยากรบรรเทาทุกข์ และการวิเคราะห์ข้อมูลผ่าน Dashboard และแผนที่ เพื่อให้การช่วยเหลือเป็นไปอย่างมีประสิทธิภาพและทั่วถึง

🏕️

ติดตามความจุ (Capacity) และผู้อาศัยจริง (Occupancy) ของศูนย์พักพิงแต่ละแห่งแบบ Real-time

📊

แสดงผลสถิติและสถานะวิกฤตผ่าน Dashboard และแผนที่ เพื่อช่วยตัดสินใจเชิงกลยุทธ์

Features

สิ่งที่ระบบทำได้ — สต็อกสินค้า

🗂️

Inventory Categorization

แยกหมวดหมู่สิ่งของชัดเจน เช่น อาหาร ยา เครื่องนุ่งห่ม อุปกรณ์เครื่องนอน

📈

Real-time Stock Tracking

บันทึกรับเข้า-เบิกจ่ายสินค้า พร้อมปรับยอดคงคลังอัตโนมัติ

⏳

Expiry & Quality Control

ฟิลด์บันทึกวันหมดอายุและหมายเหตุสำหรับสินค้าแต่ละล็อต

📍

Multi-location Inventory

รองรับการจัดการสต็อกแยกตามศูนย์พักพิงหรือคลังส่วนกลาง

🔀

Resource Request System

จับคู่ (Matching) ความต้องการของศูนย์พักพิงกับทรัพยากรที่มีอยู่ในคลัง

📑

Data Import/Export

นำเข้าและส่งออกข้อมูลสต็อกผ่านไฟล์ Excel เพื่อวิเคราะห์และรายงานผล

User Roles

สิทธิ์ผู้ใช้งานและหน้าที่ความรับผิดชอบ

  1. 1

    ผู้ดูแลระบบ (Admin)

    เข้าถึงทุกส่วนของระบบ จัดการผู้ใช้งานและศูนย์กลาง เพิ่ม/แก้ไข/ลบ/นำเข้า-ส่งออกทรัพยากร รวมถึงโอนย้ายทรัพยากรระหว่างศูนย์

  2. 2

    เจ้าหน้าที่ (Staff)

    จัดการ Check-in/Check-out และอัปเดตสถานะความจุ บันทึกรับเข้าทรัพยากรใหม่ อัปเดตยอดคงเหลือ และตรวจสอบคลังที่รับผิดชอบ

  3. 3

    ผู้ใช้งานทั่วไป / ผู้ประสบภัย (User)

    ค้นหาและดูสถานะศูนย์พักพิง (ว่าง/เต็ม) ตำแหน่งที่ตั้ง และข้อมูลการติดต่อผ่านหน้าหลัก — ไม่สามารถเข้าสู่ระบบหลังบ้านได้

Development Process

ขอบเขตการทำงานของระบบ

  1. •

    Shelter Management

    ติดตามความจุและผู้อาศัยของศูนย์พักพิงแบบ Real-time

  2. •

    Resource Management

    ควบคุมและกระจายสิ่งของบรรเทาทุกข์ไปยังจุดที่จำเป็น

  3. •

    Data Visualization

    Dashboard และแผนที่แสดงสถิติและสถานะวิกฤต

  4. •

    Role-based Access

    แบ่งสิทธิ์ 3 ระดับ Admin / Staff / User ผ่าน NextAuth.js

Challenges & Solutions

ปัญหาที่พบ กับวิธีแก้

ไม่รู้สถานะความจุศูนย์พักพิงแบบทันเวลา

ระบบติดตามความจุและ Occupancy แบบ Real-time ต่อศูนย์

กระจายทรัพยากรไม่ตรงจุด ตรวจสอบยาก

Resource Request System จับคู่ความต้องการกับทรัพยากรในคลังโดยตรง

ข้อมูลสต็อกกระจายหลายที่ ไม่มีความรับผิดชอบชัดเจน

Multi-location Inventory แยกสต็อกตามศูนย์/คลังส่วนกลาง พร้อมสิทธิ์ผู้ใช้ 3 ระดับ
