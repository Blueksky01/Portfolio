Overview

โครงงานคืออะไร

MarketHub ให้ผู้ค้าเลือกล็อค จอง ชำระเงิน และดูสัญญาเช่าได้เอง ส่วนแอดมินจัดการโซน ล็อค การอนุมัติจอง การจ่ายเงิน และการคืนเงินผ่านหน้า Dashboard เดียว ปัญหาเดิมคือการจองล็อคตลาดทำด้วยกระดาษ/แชท ตรวจสอบล็อคว่างยาก อนุมัติช้า และไม่มีประวัติย้อนกลับได้ — ระบบนี้ผูก state ของล็อค (ว่าง/จอง/เช่าอยู่) เข้ากับ booking และ payment โดยตรง พร้อม audit log ทุกการเปลี่ยนแปลง

🏪

ระบบนี้คือระบบจัดการการเช่าพื้นที่ล็อคในตลาด ตั้งแต่การจอง → อนุมัติ → ชำระเงิน → แจ้งเตือนต่อสัญญา ไม่ใช่ระบบ POS หรือ marketplace ขายสินค้า

📜

ผู้ค้าจองล็อคได้เองแบบ real-time เห็นสถานะล็อคตรงกับความจริงเสมอ แอดมินลดงานเอกสารและมีหลักฐานย้อนหลังทุกธุรกรรม

Features

สิ่งที่ระบบทำได้

🗓️

Calendar Picker

ดูล็อค/โซนตลาดพร้อมปฏิทินความว่าง ค้นหาและบุ๊กมาร์กล็อคที่สนใจ

📆

Booking + Queue

จองล็อคแบบรายวัน/รายสัปดาห์/รายเดือน พร้อมระบบคิวกรณีล็อคไม่ว่าง

🧾

OCR Slip Verification

อัปโหลดสลิปโอนเงิน ตรวจสอบด้วย OCR (Tesseract.js) ก่อนส่งให้แอดมินอนุมัติ

🔔

Notifications

แจ้งเตือนอัตโนมัติ (ต่อสัญญา, สถานะจอง) ผ่าน in-app notification และอีเมล (Resend)

🛠️

Admin Dashboard

จัดการโซน/ล็อค อนุมัติ/ปฏิเสธการจอง ตรวจสอบการชำระเงิน คืนเงิน จัดการพนักงาน export เป็น Excel

⏱️

Cron Automation

ตรวจสัญญาใกล้หมดอายุและปลดล็อคอัตโนมัติผ่าน scheduled job

System Workflow

เส้นทางของการจองล็อค 1 ครั้ง

  1. 1

    เลือกล็อค

    ผู้ค้าเลือกล็อคจากปฏิทินความว่าง

  2. 2

    จอง (PENDING)

    ถ้าล็อคไม่ว่าง เข้าคิวและรับแจ้งเตือนเมื่อว่าง

  3. 3

    อัปโหลดสลิป + OCR

    ตรวจสอบสลิปโอนเงินด้วย Tesseract.js

  4. 4

    แอดมินตรวจสอบ/อนุมัติ

    ยืนยันการชำระเงิน สถานะเปลี่ยนเป็น APPROVED

  5. 5

    เช่าอยู่ (ACTIVE)

    สัญญาเริ่มมีผล ล็อคเปลี่ยนสถานะเป็นเช่าอยู่

  6. 6

    ต่อสัญญา / สิ้นสุด

    ใกล้หมดสัญญาได้รับแจ้งเตือน เลือกต่อสัญญาหรือสิ้นสุด

Development Process

ลำดับการพัฒนา

  1. •

    ออกแบบ Data Model

    User, Zone, Lock, Booking, Payment, Refund, Queue, InterestList, Notification, AuditLog

  2. •

    วาง Route Groups ตามสิทธิ์

    (auth) หน้า login/register, (user) หน้าผู้เช่า, (admin) หน้าแอดมิน

  3. •

    ผูก Booking กับ Lock State

    state ล็อคเปลี่ยนได้ผ่าน booking/payment flow เท่านั้น

  4. •

    เพิ่ม OCR + Notification

    ตรวจสลิปด้วย Tesseract.js แจ้งเตือนผ่าน in-app และ Resend

  5. •

    เชื่อม Cron + Deploy

    scheduled job ตรวจสัญญาใกล้หมดอายุ, deploy บน Vercel / Docker

Challenges & Solutions

ปัญหาที่พบ กับวิธีแก้

จองล็อคด้วยกระดาษ/แชท ตรวจสอบล็อคว่างยาก

ผูก state ล็อคเข้ากับ booking โดยตรง เห็นสถานะตรงกับความจริงเสมอ

อนุมัติช้า ต้องตรวจสลิปด้วยตาเอง

ตรวจสอบสลิปด้วย OCR (Tesseract.js) ก่อนส่งให้แอดมินอนุมัติ

ไม่มีประวัติตรวจสอบย้อนกลับได้

ทุกการเปลี่ยนสถานะสำคัญ (อนุมัติ, คืนเงิน, ปลดล็อค) บันทึกใน AuditLog

ล็อคไม่ว่างแต่ผู้ค้ายังอยากจอง

ระบบ Queue และ Interest List ให้เข้าคิวและรับแจ้งเตือนเมื่อล็อคว่าง
