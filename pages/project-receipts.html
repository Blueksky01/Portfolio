Overview

โครงงานคืออะไร

ฟีเจอร์นี้เกิดจากปัญหาจริงในระบบสมัครแข่งขันหุ่นยนต์ — ทุกใบเสร็จต้องผ่านแอดมินอนุมัติ ทำให้ผู้ใช้ต้องรอนาน และแอดมินต้องคีย์ข้อมูล/รวมยอดเองเมื่อผู้ใช้สมัครแข่งขันหลายรายการพร้อมกัน จึงออกแบบให้ผู้ใช้ยื่นคำขอใบเสร็จได้ด้วยตนเอง (self-issue) โดยแอดมินยังตรวจสอบย้อนหลังได้เสมอ

⚡

ตัดขั้นตอนรออนุมัติออกจาก flow หลัก ผู้ใช้ออกใบเสร็จได้ทันทีที่ต้องการ

🧾

รวมหลายรายการสมัครของผู้ใช้คนเดียวกันเป็นใบเสร็จใบเดียว พร้อมคำนวณยอดรวมอัตโนมัติ

Features

สิ่งที่ระบบทำได้

🙋

Self-Issue Receipt

ผู้ใช้ยื่นคำขอใบเสร็จได้เอง ไม่ต้องรอแอดมินอนุมัติทุกครั้ง

➕

Merge Registrations

รวมหลายรายการสมัคร (registrations) เป็นใบเสร็จใบเดียว คำนวณยอดรวมอัตโนมัติ

🖨️

A4 Print Layout

หน้าพิมพ์ใบเสร็จขนาด A4 พร้อมแปลงจำนวนเงินเป็นตัวอักษรไทยอัตโนมัติ เช่น 1500 → หนึ่งพันห้าร้อยบาทถ้วน

📍

Cascading Address Form

ฟอร์มเลือกที่อยู่แบบลำดับหมวดหมู่ จังหวัด → อำเภอ → ตำบล

🛠️

Admin Review

แอดมินตรวจสอบคำขอใบเสร็จย้อนหลังได้ แม้ผู้ใช้จะออกใบเสร็จเองแล้ว

System Workflow

เส้นทางของคำขอใบเสร็จ 1 ใบ

  1. 1

    สมัครแข่งขัน

    ผู้ใช้สมัครแข่งขันหนึ่งหรือหลายรายการ

  2. 2

    ยื่นคำขอใบเสร็จ

    เลือกรายการสมัครที่ต้องการรวมในใบเสร็จ กรอกที่อยู่ผู้รับ

  3. 3

    ระบบคำนวณยอดรวม

    รวมยอดจากทุกรายการสมัคร แปลงจำนวนเงินเป็นตัวอักษรไทย

  4. 4

    ออกใบเสร็จทันที

    ผู้ใช้พิมพ์ใบเสร็จ A4 ได้เองโดยไม่ต้องรออนุมัติ

  5. 5

    แอดมินตรวจย้อนหลัง

    แอดมินเข้าดูและตรวจสอบคำขอใบเสร็จที่ออกไปแล้วได้ตลอด

Challenges & Solutions

ปัญหาที่พบ กับวิธีแก้

ทุกใบเสร็จต้องรอแอดมินอนุมัติ ผู้ใช้รอนาน

เปิดให้ผู้ใช้ออกใบเสร็จเอง (self-issue) แอดมินตรวจย้อนหลังแทนการอนุมัติล่วงหน้า

แอดมินต้องคีย์และรวมยอดเองเมื่อผู้ใช้สมัครหลายรายการ

ระบบรวมหลายรายการสมัครเป็นใบเสร็จเดียวและคำนวณยอดรวมอัตโนมัติ

ใบเสร็จต้องมีจำนวนเงินเป็นตัวอักษรไทยตามมาตรฐานเอกสารการเงิน

เขียนตัวแปลงตัวเลขเป็นตัวอักษรไทยอัตโนมัติในหน้าพิมพ์ A4

กรอกที่อยู่ผิดพลาดบ่อยเมื่อพิมพ์เอง

ใช้ฟอร์มเลือกที่อยู่แบบลำดับหมวดหมู่ จังหวัด → อำเภอ → ตำบล ลดความผิดพลาด
