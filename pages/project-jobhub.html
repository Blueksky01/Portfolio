Overview

โครงงานคืออะไร

JobHub เป็นแอปมือถือสำหรับหางานและโพสต์งาน พัฒนาด้วย Flutter โดยใช้ GetX เป็นตัวจัดการ state ทั้งหมด แอปเชื่อมต่อกับ Backend ผ่าน REST API สำหรับข้อมูลงาน การสมัคร และผู้ใช้ พร้อมใช้ Socket.IO เพื่อรองรับการแชทและการแจ้งเตือนแบบเรียลไทม์ระหว่างผู้ว่าจ้างกับผู้สมัคร

📱

โครงสร้างโปรเจกต์แบ่งชัดเจนตามหน้าที่ — controllers / services / model / screens / routes ตามแนวทาง GetX

💬

แชทและแจ้งเตือนทำงานแบบเรียลไทม์ผ่าน Socket.IO ไม่ต้องรอรีเฟรชหน้าจอ

System Workflow

เส้นทางการใช้งานแอป

  1. 1

    สมัคร/เข้าสู่ระบบ

    ผู้ใช้ล็อกอินผ่าน auth_service และ auth_controller

  2. 2

    ดูงานบน Dashboard

    เรียกดูรายการงานทั้งหมดและค้นหางานที่สนใจ

  3. 3

    สมัครงาน / โพสต์งาน

    ผู้สมัครยื่นใบสมัคร หรือผู้ว่าจ้างโพสต์งานใหม่

  4. 4

    แชทระหว่างกัน

    สื่อสารแบบเรียลไทม์ผ่าน socket_service

  5. 5

    รับการแจ้งเตือน

    ระบบแจ้งเตือนความเคลื่อนไหวสำคัญผ่าน notification_service

Development Process

ลำดับการพัฒนา

  1. •

    ออกแบบโครงสร้างโปรเจกต์

    แบ่ง lib/ เป็น controllers, services, model, screens, routes

  2. •

    สร้างระบบ Authentication

    auth_service + auth_controller จัดการ token และ session

  3. •

    พัฒนา Job CRUD

    job_service เชื่อมกับหน้า dashboard, create, edit, detail

  4. •

    เพิ่ม Real-time Layer

    socket_service สำหรับแชทและ notification_service สำหรับแจ้งเตือน

  5. •

    เติมฟีเจอร์ Wallet และ Profile

    wallet_service และ profilePage ปิดท้ายฟีเจอร์หลักของแอป

Challenges & Solutions

ปัญหาที่พบ กับวิธีแก้

การแจ้งเตือนและแชทต้องอัปเดตทันที ไม่ใช่รอโหลดหน้าใหม่

ใช้ Socket.IO ผ่าน socket_service ให้ chat และ notification ทำงานแบบเรียลไทม์

state ของแอปกระจาย จัดการยากเมื่อฟีเจอร์เพิ่มขึ้น

รวมศูนย์ด้วย GetX controller แยกตามโดเมน เช่น auth, chat, notification

โค้ด UI และ logic การเรียก API ปนกัน

แยกชั้น services/ ออกจาก screens/ ให้แต่ละหน้าจอเรียกใช้ผ่าน controller เท่านั้น
