Overview

โครงงานคืออะไร

เว็บแอปบริหารหอพักสำหรับ Admin จัดการห้อง/บิล/ผู้เช่า และ Tenant เลือกห้อง ชำระเงิน อัปโหลดสลิปโอนเงิน — ระบบใช้ Tesseract OCR อ่านสลิปช่วยตรวจสอบเบื้องต้น ก่อนให้ admin ตรวจสอบ/อนุมัติ/ปฏิเสธจริงผ่าน dashboard

🚫

ระบบนี้ไม่ใช่ payment gateway ไม่ตัดเงินจริง เป็นการตรวจสลิปโอนเงินด้วยมือ + OCR ช่วย ไม่ใช่ระบบบัญชี/ภาษีเต็มรูปแบบ

🔒

ทุกสถานะห้อง/บิลเดินตามกฎธุรกิจที่ชัดเจน ป้องกันห้อง "ค้าง" สถานะผิดหรือถูกจองซ้ำ

System Workflow

เส้นทางการจองห้องหนึ่งครั้ง

  1. 1

    เลือกห้อง + ส่งสลิป

    Tenant เลือกห้องว่างและอัปโหลดสลิปโอนเงิน

  2. 2

    ห้องเปลี่ยนเป็น Pending

    Room: vacant → pending ห้องหายจากรายการห้องว่างทันที กันจองซ้ำ / Bill: pending

  3. 3

    Admin ตรวจสลิป

    ตรวจสอบสลิปที่ OCR ช่วยอ่านแล้ว

  4. 4

    อนุมัติ

    Bill → verified, Room → occupied

  5. 5

    ปฏิเสธ (ทางเลือก)

    Bill → rejected, Room → pending → vacant พร้อมลบ tenant ออกจากห้อง

Challenges & Solutions

ปัญหาที่พบ กับวิธีแก้

ผู้เช่าเลือกห้องแล้วกด "ชำระเงิน" แต่ยังไม่จ่ายจริง ระบบล็อกห้องเป็น "เช่าแล้ว" ทันที ทำให้คนอื่นจองห้องเดิมไม่ได้ทั้งที่ยังไม่มีใครจ่ายเงินจริง

เพิ่มสถานะห้อง pending คั่นระหว่าง vacant กับ occupied ห้องจะ "เช่าแล้ว" จริงก็ต่อเมื่อ admin ตรวจสลิปแล้วอนุมัติเท่านั้น

บิลถูกปฏิเสธแล้วห้องยังค้างสถานะเดิม ไม่มีใครจองซ้ำได้

บิลที่ rejected ต้องคืนห้องเป็น vacant และลบ tenant ออกจากห้องเสมอ เป็นกฎธุรกิจบังคับ
